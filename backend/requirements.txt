# ── 배포 준비, 2026-08-20 ───────────────────────────────────────────────────
# `app/dataset.py` 가 모듈 스코프에서 `ZoneInfo("Asia/Seoul")` 를 만든다. 표준
# 라이브러리 `zoneinfo` 는 **시스템 tz 데이터베이스를 읽는데 Windows 에는 그런
# 것이 없다** — 그래서 이 백엔드가 도는 Windows 호스트에서는 tzdata 가 사실상
# 필수다. 개발 기계에서 안 터진 이유는 pandas/pydantic 같은 다른 패키지가
# 곁다리로 깔아 두었기 때문이고, 그건 이 파일 머리글이 numpy/scipy 에 대해
# 적어 둔 사고와 **정확히 같은 모양**이다.
#
# 격리 venv 에 이 파일만 깔고 import 를 돌려 실제로 재현했다(2026-08-20):
#   ZoneInfoNotFoundError: 'No time zone found with key Asia/Seoul'
#   — app.main / app.dataset / app.backtest / app.rv / app.cashbond / app.surface3d
#
# 하한은 지금 깔려 있는 판이다. 이 패키지는 코드가 아니라 **데이터**(IANA
# 스냅숏)라 위를 막지 않는다 — 한국은 서머타임이 없어 갱신이 값을 바꾸지 않고,
# 위를 막으면 다른 나라 시간대가 필요해지는 날 조용히 낡는다.
tzdata>=2026.3
