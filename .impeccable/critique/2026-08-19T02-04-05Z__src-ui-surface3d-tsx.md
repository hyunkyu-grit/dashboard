## Anti-Patterns Verdict

"이것은 슬롭의 반대편 실패면이다" — 모든 결정이 실측·오너 판정으로 소급된다. 정적 디텍터 0건(--no-config 재검증). 인페이지 3건 전부 기지/역외(캡션 행간=CDS legal 토큰 성질·strip·body). 캔버스 내부는 디텍터 사각 — P1 들은 A 의 육안 실측.

## Priority Issues

1. **[P1] 흔한 창 높이에서 캔버스 하단 클리핑 — 축 라벨 증발.** 실측 innerHeight 855: 캔버스 바닥 824 vs 호스트 클립 796 → 정면 1Y·2Y 라벨 소실, 탑뷰 연도 반토막(양 테마). 원인 = 높이를 `innerHeight − top − 44` 로 **추정**하는데 실제 제약은 100vh flex 열이라 ~28px 어긋남(554-566). Fix: 추정 대신 실측 — 앱에 이미 있는 `useFillHeight` 관용구.
2. **[P1] 알약이 보조기술에 무명.** read_page 재실측: 이름 없는 tab 15개 — 스크린리더는 국고와 위에서를 못 가른다(2차 지적의 재확인; DOM 텍스트는 있으나 a11y 트리 이름이 비어 있음 — CDS SegmentedTab 렌더링 문제로 보임). Fix: CDS per-tab accessibilityLabel 경로 확인, 불가면 SegmentedTabs 검토.
3. **[P2] 고스트 칩이 ×를 둘째 줄로 접고 캔버스를 밀어내림.** 칩 등장/해제 순간 플롯이 ~30px 이동 — 두 커브를 비교하는 바로 그 순간에 화면이 움직인다. Fix: nowrap/end 슬롯 + 캡션 줄 높이 예약.
4. **[P2] 카메라가 데이터 필터로 위장 + 그룹 위치 점프.** 크레딧 전환 시 발행체 삽입으로 테너·구도가 ~600px 이동. Fix: 구도만 우측 끝 고정 + 헤어라인 분리. (그룹 라벨 약함은 18차 직후 머리 재구성으로 부분 해소)
5. **[P3] 기본 뷰 금리 눈금 1개("2%").** step 로직(span>4→2)과 겹침 드랍의 합작. Fix: span/4 nice-number ~4눈금 + 기준금리/CD 리드아웃에 % 접미.

## Cognitive Load

실패 4~5: 4의미 1의상·그룹 점프·칩 리플로·"내가 어디 있나" 무명·눈금 1개. 통과: 자리기억·빈 풀 탈출구·hover 규칙.

## What's Working

1. **데이터 정직성이 디자인 시스템** — 구역 스냅=실측만·ext 범례·as-of 원값·구멍 비가교.
2. **한 계약 두 채널** — 키보드=마우스, aria-live 가 전체 리드아웃 미러(실측), 포커스 링.
3. **제품 문법 통합** — 카드+컨트롤 머리+풀블리드가 메인·백테스트와 일치.
