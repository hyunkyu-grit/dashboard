## C.1 엣지리스트 — 코드에서 뽑았다. 된다

`backend/wiring/edges.py` (신규, 세션 3 소유). `bigfoot/**` 는 동결이라 읽기만
한다.

```
python -m wiring.edges
→ nodes 34 · edges 90 · uncovered 2 · unsupported 0
   backend/output/wiring_graph.json
```

### 어떻게 뽑나

솔버의 기간 루프 본문은 전부 선형이다(기저가 `linearity_gate` 로 그 사실을 따로
잠근다). 그래서 `new["K"] = <선형결합>` 을 항별로 편다.

| 통로 | 방법 |
|---|---|
| `u["v"]` · `new["v"]` · `lag("v", t)` | AST 리터럴 |
| `self.<...>` 만 든 부분식 | **살아 있는 `BigfootSystem` 에 대고 eval** — 계수는 추정이 아니라 실측이고, `Coefficient.source` 가 부록 D 슬롯 주소를 준다 |
| `self.pp.core_inflation(...)` 처럼 몸통이 `korea.py` 에 있는 호출 | **수치미분**(단위벡터 한 번). 선형함수라 정확하다. korea.py 를 또 파싱하는 것보다 실제 함수를 재는 쪽이 낫다 |
| `self.w40 @ x_t` · `self.wF @ x_tm1` | 왼쪽을 수치벡터로 풀고 `np.array([...])` 원소마다 나눠 붙인다 |
| `for key, ekey, eq, rname in [...]` | 리터럴 튜플로 펼친다 |

세션 1 시제품이 못 잡았다고 적어 둔 **여덟 자리를 전부 잡았다** — `kr10y`·`kr3y`
(상태벡터), `r_hh`·`r_firm`(변수 키 루프), `m`·`i_con`·`dhpi`·`ddebt`(중간
지역변수).

### 장기/단기는 계수 주소가 가른다

**슬롯 주소에 `.target.` 이 있으면 LR, 아니면 SR.** 목표식(공적분)이 장기
행태식이고 성장식(PAC/오차수정)이 단기라는 논문의 설계가 그대로 규칙이 된다.
손으로 라벨을 붙이지 않는다.

그 규칙 하나로 논문의 서명 같은 쌍이 자동으로 선다:

```
debt → c   LR  −   eq 7  p.16  consumption.target.slots[1]
debt → c   SR  +   eq 8  p.17  consumption.growth.slots[4]
```

### 접은 것 — 증분 변수 여섯

`new[X] = lag(X, t) + new[dX]` 는 배선이 아니라 **회계**다. 이 꼴을 AST 로 찾아
`dX` 를 `X` 로 접는다(`dc·ddebt·dg·dhpi·di·di_con`). **안 접으면 `debt → c`
화살표가 하나도 안 선다** — 코드에서 단기 쪽은 `ddebt → dc` 로 흐르기 때문이다.
접는 규칙도 코드에서 뽑는다. 손으로 정하면 어느 쌍을 접었는지 화면이 말할 수 없다.

### 표현 못 한 것 (`uncovered` 2건, 비워 두지 않았다)

| 자리 | 왜 |
|---|---|
| `us_y`·`us_pi`·`us_i` | 미국 블록은 완전예견 **적층 선형해**라 기간별 대입문이 없다. 안쪽 배선(IS·필립스·준칙)은 그래프에 안 서고, **미국이 한국으로 나오는 통로만** 선다(`us_i → s`, `us10y → kr10y`, `us_y → f_*`, `us_y → x`) |
| eq (29)(30) 세계 수출물가 | 외생이라 그 자리에 환율이 서 있다(`WIRING_PX_EXOG`). 화살표는 `s → pm` 으로 보인다 |

`unsupported_expressions` 는 **0** 이다. 못 편 식이 없다.

### 만드는 도중에 잡은 자기 결함 둘 (기록)

1. **항을 슬롯 출처로 안 가르면 부호가 섞인다.** 같은 참조가 목표항(장기)과
   성장항(단기) 양쪽에 나올 때 한 덩어리로 더해져 합의 부호가 어느 쪽도 아닌
   값이 됐다. `c → m` 장기가 실제로는 **+0.043** 인데 −로 나왔다
   (α_M0 0.1477 × β_M1 1.3916 × z_C 0.21). 키에 슬롯을 넣어 닫았다.
2. **계수의 방정식 번호는 «도착 변수» 가 아니라 «그 계수가 사는 슬롯 그룹» 이
   말한다.** 유가→소비자물가가 eq 25 로 찍혔는데 그 계수는 eq 31(수입물가
   목표식) 것이었다.

## C.2 배선 대 인쇄 — **이게 UI 얘기가 아니라 모형 얘기다**

엣지가 붙은 인쇄식 26개:
`5 6 7 8 11 12 14 16 17 19 20 22 23 24 25 26 27 28 31 32 33 35 36 38 40 44`

안 붙은 인쇄식 18개: `1 2 3 4 9 10 13 15 18 21 29 30 34 37 39 41 42 43`

대부분은 **정당하게** 안 붙는다 — PAC 틀 정의(2·3), 편차 공간에서 상수로 사라지는
목표식(15), 짝 안쪽 번호(37·39·41·43), 항등식(13·21은 다른 식 안에서 계산됨).
그런데 **정당하지 않은 것이 셋** 있다.

### ① 설비투자에 금리가 안 들어간다 — eq (9) 의 `− UC_{I,t}` 미배선 🔴

논문 인쇄 p.18 을 렌더해서 읽었다:

```
ln I*_t = β_I0 + β_I1 ln Ȳ_t + β_I2 Dummy_20Q2 − UC_{I,t}            (9)
UC_{I,t} = (i_Firm,t + i_CB,t)/2 − π^yoy_cpi,t/4 + δ_{I,t}           (10)
Δln I_t = α_I0(ln I*_{t-1} − ln I_{t-1}) + α_I1 Δln I_{t-1}
          + E_t[Σ d_k Δln I*_{t+k}] + γ_I1 Δŷ_t + γ_I2 Δln P_{I,t}
          + γ_I3 ln DRAM_t + u_{I,t}                                  (11)
```

자본 사용자비용이 **목표식 안에 계수 −1 로** 들어 있다. 그런데 구현의
`investment_fi_target` 은 `{const, potential, covid_dummy}` 셋뿐이고, 솔버는
목표 편차를 **문자 그대로 `0.0`** 으로 둔다:

```python
new["di"] = (self.inv.alpha.value * (0.0 - lag("i_fi", t)) + ...)
```

결과: **설비투자로 들어가는 엣지가 `y_gap → i_fi` 하나뿐이다.** 정책금리가
설비투자에 닿는 통로가 산출갭 하나밖에 없다. 건설투자(eq 12–14)는 같은 사용자
비용이 제대로 배선돼 있어서(`cb`·`kr10y`·`r_firm`·`cpi_yoy` → `ih_star`) 두
블록이 **비대칭**이다.

이건 8/21 감사가 eq 21 에서 잡은 것과 **같은 종류**다 — 값이 아니라 배치.
그리고 스코어카드에 직접 닿는다: 논문의 미국 +25bp 패널에 설비투자 −0.02% 가
있는데, 우리 `i_fi` 는 갭으로만 움직인다.

### ② eq (11) 의 γ_I2·γ_I3 도 안 붙어 있다

`investment_growth` 객체는 `deflator`·`semiconductor` extras 를 들고 있지만
**솔버가 그 둘을 안 부른다.** γ_I3 는 Gartner DRAM 지수(유료)라 어차피 못 넣는
자리인데, γ_I2 투자 디플레이터는 데이터가 있다(`bigfoot_defl_fi_q.csv`).

### ③ PAC 기대항은 소비에만 있다 — 8/21 뒤에도 그대로다 (확인함)

`PLAIN_ECM_NON_CONSUMPTION` 이 여전히 참이다. 그래프가 **스스로** 그렇게 말한다 —
`via: "PAC 기대항 (부록 A.11~A.16)"` 을 단 엣지는 `i_kr → c`·`pi_core → c` 둘뿐이고,
eq (11)(14)(19)(22)(30)(32) 로 가는 엣지에는 하나도 없다. 오버레이를 **손으로
적을 필요가 없다.**

### ④ 방정식 번호 라벨 오류 (값 아님)

`korea.py::investment_growth` 가 스스로를 `eq_no='10'` 이라고 부른다. PDF 인쇄
p.18 에서 (10) 은 자본 사용자비용 정의이고 설비투자 성장식은 **(11)** 이다.
배선은 맞고 **라벨만** 틀렸다. 엔진은 동결이라 안 고쳤다 —
`wiring/edges.py::EQ_NO_CORRECTIONS` 가 논문 번호를 들고, 화면이 둘 다 보여준다.

### 부록 D 상태가 배선을 못 따라왔다

`appendix_d_resolved.yaml` 에서 `construction.*` 9슬롯과 `government.*` 6슬롯이
아직 `EXOG_V1`(«Phase 2 에서 추세 고정»)인데, 8/21 에 두 블록이 **해동돼 지금
배선돼 있다**(그래프의 eq 12·14·16 엣지가 그 증거다). 상태 라벨이 15건 낡았다.
계수표가 그 사실을 적는다.

## C.8 백테스트 실현가능성 — **안 된다.** 막는 것 다섯

2021Q3–2023Q1 인상 사이클. 기간을 바꾸지 않았고, 조건집합을 좁혀서 좋아 보이게
하지도 않았다.

| # | 막는 것 | 실측 |
|---|---|---|
| 1 | **초기상태가 없다** | `BigfootSystem.solve()` 에 초기상태 인자가 없다. `v = {k: np.zeros(T)}` 이고 `lag()` 는 t<0 에서 0 을 준다 — **모든 실행이 정상상태에서 출발**한다 |
| 2 | **양측 HP 필터** | `residuals.py` 가 `LOOKAHEAD` 깃발을 스스로 달고 있다. 2021Q3 의 «실현 편차» 가 2026 까지의 데이터로 만든 추세에서 나온다. 빈티지가 아니다 |
| 3 | **빈티지 재추정이 없다** | 계수는 논문 부록 D(전표본 2000Q1–2024Q2)이고 위성 VAR 은 2026Q2 까지로 추정된다. 백테스트 창이 추정표본 **안에** 있다 |
| 4 | **레벨 제품이 없다** | 엔진은 편차만 낸다. Table 1 의 RMSE 는 예측오차(레벨)다. 빈티지별 베이스라인 레벨 경로를 만들 기계가 없다 |
| 5 | **외생 대체** | Part B 의 대체분(가처분소득·Gartner·세계 수출물가·건축착공·중국)이 전부 레벨에만 물린다 — 그런데 백테스트는 레벨 제품이다 |

### 막는 것 ①의 크기를 쟀다

빈티지가 서려면 모형이 2021Q2 의 실제 상태에서 출발해야 한다. 그 상태는(같은
편차 규약으로):

```
y_gap +0.44pp · cpi_yoy +0.49pp · hpi +2.98% · debt +2.08pp
i_kr −1.05pp · kr10y −0.25pp · c −1.29% · s −7.08 log%
```

솔버는 이걸 **전부 0 으로 두고 시작한다.** 주택 +2.98%·부채 +2.08pp 를 버리는데,
그 둘이 정확히 스코어카드 실패 넷이 사는 사슬이다.

### 그래도 돌려 봤다 — «백테스트» 가 아니라 **정합성 점검**

실현 정책금리 편차 7분기를 부록 B 핀으로 물리고(`pin={"i_kr": ...}`,
`conditioning_map` 의 `kr_policy` 그룹), 모형 `kr10y` 를 실현 `kr10y` 와 견줬다.
전표본 추정·양측 HP·초기상태 0 — 셋 다 그대로다. **시험이 아니다.**

```
실현 i_kr 편차   −1.044 −0.893 −0.639 −0.405 +0.201 +0.844 +1.156
실현 kr10y 편차  −0.439 −0.195 +0.066 +0.703 +0.732 +1.042 +0.508
모형 kr10y 편차  −0.116 −0.037 −0.015 −0.002 +0.053 +0.089 +0.084
```

RMSE **55.8bp**. 아무것도 안 한 벤치마크(편차 0 유지) **61.0bp**. 비율 **0.91**.

읽히는 것은 정확도가 아니라 **구조**다. 실현 장기금리가 104bp 움직인 구간에서
모형은 **8.9bp** 를 낸다. 원인은 기대가설이다 — `kr10y` 는 단기금리 경로의
**40분기 평균**이라 7분기짜리 혹은 1/6 도 안 실린다. 여기에 초기상태 0 과
`V1_NO_TERM_PREMIUM_IN_IRS` 가 겹친다.

**출하 결정**: `output/backtest_2021_cycle.json` 은 막는 것 목록과 이 실측을
담고, Method 면은 «아직 못 한다, 하려면 이게 필요하다» 를 내용으로 세운다.

## C.4 앵커 대조 — 지평을 잘못 잡으면 또 헛진단이 나온다

옳은 규약: **논문 부호와 같은 쪽의 극값**(`min` 또는 `max`), 24분기 전 구간.
