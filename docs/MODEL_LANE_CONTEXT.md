## 4. 사슬과 입력 층위

```
정책 경로 → 엔진 (준칙 eq 35 · EH 기간구조 eq 36/37 · β_sync 1.05 · tp_us FIR K=12)
         → 국고 3년/10년
         → cd_layer (CD − 기준금리 21.5bp · τ 78.8영업일)
         → OU 스프레드 위성 (krwswapdata 13테너 2016-01~2026-08)
         → IRS 커브
```

- **Layer 1** 정책금리 경로 — 오너가 타이핑하는 유일한 것. 부록 B 역산
- **Layer 2** 가정 — 자동으로 채우고 **보여주되 절대 편집 불가**
- **Layer 3** 상태·이력 — ECOS/FRED, 엔진 적재가 처리

### ⚠ Layer 2 에 대해 진단이 계획을 뒤집었습니다 — 읽고 시작하세요

원래 설계는 「미 정책금리: FOMC 닷 · 유가: 브렌트 선물 · 해외성장: 컨센서스」를
띠에 세우는 것이었습니다. **그 띠는 거짓말이 됩니다.**

실측(`output/foundation_diagnosis.md` §C.8):

```
r* 를 1.5% · 2.5% 로 바꿔 기저를 다시 풀었다
  → 15개 기저 전부의 10년 IRS 반응 최대 절대차 = 0.000000 bp
```

구조적입니다. eq (35) 에서 `r*` 와 `−φ_π·π*` 는 **가법 상수**이고, 베이스라인 0
인 편차 공간에서 상수는 소거됩니다. 모형이 선형이라(게이트 1e-4) 상태의존성도
없습니다.

그리고 미 정책금리·유가·해외성장은 기저가 **단위 충격**으로 담습니다 — `us_4q`
는 «가정된 미국 경로» 가 아니라 «미국이 +100bp 가면» 입니다. FOMC 닷을 새로
받아와도 **기저의 숫자는 하나도 안 바뀝니다.**

그래서 `assumptions.json` 의 모든 항목이 `effect` 를 답니다:

```
delta         화면의 bp 를 실제로 움직인다        ← 지금 해당 없음
level_only    레벨 전망에만                      ← r* · π*
not_in_basis  기저가 아예 안 쓴다               ← 미 정책금리 · 유가 · 해외성장
```

**「r\* 2.0% — ±0.5%면 10년이 ±XXbp」 줄의 XX 는 0 입니다.** 숫자를 지어내지
말고 문장으로 쓰세요. 예: 「`r*` 는 레벨을 움직이고 이 화면은 델타를 보여줘요.
실제로 재 봤더니 0.000000bp 였어요.」

### 리베이크가 실제로 갱신하는 것은 둘뿐입니다

```
지출 비중 z_C·z_I·z_IH·z_G·z_X   ECOS 국민계정 — 분기물
위성 VAR                          근원CPI·콜금리·실질GDP — 분기물
```

MPC 날짜에 굽는 건 «달력을 맞추는 일»이지 «새 숫자를 받는 일»이 아닙니다.
화면이 이걸 뒤집으면 안 됩니다.

## 6. 상태 — 9/13, 그리고 12/13 은 기준선이 아닙니다

44개 인쇄식을 전수 대조했습니다(2026-08-21). 값 옮겨 적기는 원래 맞았고 틀린
것은 늘 **배치**였습니다 — eq 23/24 어트랙터 필립스, eq 19 환율 Δ₄, eq 8/11 Δŷ,
eq 21 에 IH·G 포함, eq 40/42 전가 1.0 + 스프레드 AR.

**예전 12/13 은 Table 8 값의 순열을 그 밴드에 맞춰 고른 과적합입니다.** 기준선이
아닙니다. 남은 실패 넷은 전부 금리→주택→부채→소비 **진폭** 사슬이고, 뿌리는
논문이 안 박은 **금리 단위 규약**입니다. 밴드를 맞추려 배율을 지어내지 마세요 —
그게 애초에 고치러 온 잘못입니다.

국내 기저 꼬리는 크게 좋아졌습니다: `|q24|/max` 가 gap 1.00→0.21 ·
exports 0.90→0.17 · oil 0.49→0.03.
